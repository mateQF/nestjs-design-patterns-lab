# NestJS Design Patterns Lab

Este repositorio tiene como objetivo practicar patrones de diseño aplicados a proyectos reales con NestJS.

La idea no es mostrar ejemplos aislados o puramente teóricos, sino implementar cada patrón dentro de un pequeño módulo funcional, simulando situaciones comunes de backend como productos, órdenes, pagos, servicios, validaciones y reglas de negocio.

## Objetivo del repositorio

Este proyecto funciona como un laboratorio de aprendizaje para implementar patrones de diseño en NestJS de forma ordenada, progresiva y profesional.

Cada carpeta dentro de `src/patterns` representa un patrón distinto.
